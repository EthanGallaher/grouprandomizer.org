Local-first storage

Class names, student names, performance tiers, source names from PDF imports, separation rules, and seating assignments are saved in this browser's local storage. Google sign-in requests basic identity information (your email and profile). When enabled, this browser encrypts rosters, rankings, class settings, and seating charts before sending them to Cloud Firestore. The encryption key is stored locally using IndexedDB and does not come from Google sign-in. A new device must be approved by an existing device. Local classroom records and manual JSON backups remain readable, and privileged code running in the browser can access them. Cloud sync remains off until explicitly enabled and must not be used with actual students without district approval. Disconnecting Google does not erase local data or cloud data. You can delete the cloud copy separately. The PDF reader is bundled with the app and PDF parsing occurs in the browser. Other browser extensions or users of this browser profile may be able to access local data. Backups contain student information and must be stored securely. Clearing browser data can erase your classes. Teachers should follow their school’s applicable student-data privacy and technology policies.
