# Deploy BGR Website P05.15 to GitHub Pages

First export a verified JSON backup from your current app to a school-approved location and save a rollback of the current published files. Extract the website ZIP; upload its contents directly into the repository's published root (do not upload the ZIP instead). Confirm the updated `index.html`, icons, and `BGR-Manual-Local-Edition.zip` are present.

Hard-refresh grouprandomizer.org and reopen installed apps if a cached version persists. Do not clear local browser storage. In a fictional class verify the 2/3/4 slider, Balanced and Supportive grouping, help buttons on Groups and Layout Builder, student roles, seating templates, and previous save data.

The package does not restore or synchronize devices, migrate cloud keys, or remove previously uploaded cloud records. Use school-approved data-handling procedures.
